# Ateliê Josy’art — conceito de presença digital

Protótipo mobile-first de página única para apresentar a oficina de modelagem manual e encaminhar dúvidas sobre próximas turmas ao WhatsApp. Inclui três composições distintas selecionáveis na mesma página: Caderno, Oficina e Galeria.

As peças mostradas no perfil foram feitas por alunos e não estão à venda. A imagem usada aqui é uma referência ilustrativa gerada para o conceito; substituir por fotos autorizadas do ateliê antes de uma publicação final.

O protótipo não define preços, agenda, duração ou política de envio. As informações confirmadas foram registradas em `BRIEF_DO_PROJETO.md`.

## Arquivos

- `index.html`: conteúdo e navegação.
- `styles.css`: três composições responsivas.
- `script.js`: seletor, estado no hash, teclado e revelações respeitando movimento reduzido.
- `assets/oficina-modelagem-ilustrativa.png`: imagem conceitual da oficina.
